## New app icon (parked 2026-10-16)

The current icon stays for now. What we learned so far:

- **Problems with the current one:** it draws the UI (the notch, a spark and
  sound bars), so it turns to mush at small sizes. The spark looks like
  Claude's logo, which is a trademark risk. It's a flat PNG instead of a
  layered macOS 26 `.icon`.
- **Round 1** (Notch, Rise, Ears): rejected as too literal and too flat.
- **Round 2** (Lens, Zenith, Bead, Summit, Caret): abstract glass objects
  with an "up there" story. None was picked.
- **Next time:** start from whatever comes closest, sketch variations, then
  Mateusz draws it in Figma and builds the layers in Icon Composer.
  Comparison page: https://claude.ai/artifact/MyHe6dy9TaEusSuPgnegUy
